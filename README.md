# 🎬 MovieZone – Movie Discovery Website

MovieZone is a responsive movie discovery website designed to explore movies, genres, movie details, watchlists, and user profiles.

## 🚀 Features

- 🎬 Movie discovery interface
- 🔍 Movie search and browsing
- 🎭 Browse movies by genres
- ⭐ Movie details and ratings
- ❤️ Watchlist functionality
- 👤 User login and profile pages
- 📱 Responsive website design
- 🎨 Modern and user-friendly UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

- `index.html` – Home page
- `movies.html` – Movies page
- `movie.html` – Movie details
- `genres.html` – Genres page
- `login.html` – Login page
- `profile.html` – User profile
- `watchlist.html` – Watchlist page
- `style.css` – Website styling
- `script.js` – JavaScript functionality

## 🎯 Project Purpose

The purpose of this project is to practice frontend web development and create a movie-based website with a modern user interface.
